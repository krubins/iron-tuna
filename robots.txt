# The policy is one line: everything on this site is open to every crawler, for
# search and for AI answers alike. The wildcard block below already says that,
# and it is the block an unnamed agent obeys.
#
# The named blocks that follow add nothing technically. They are here because a
# blanket allow is ambiguous in practice — several answer engines treat an
# unnamed site as undecided rather than as open — and because naming an agent
# records a deliberate decision rather than an oversight. An agent that is
# misspelled here, or retired by its vendor, simply falls through to the
# wildcard and is still allowed, so this list can never lock anyone out.
#
# CAREFUL — THE ONE WAY THIS FILE CAN BITE. Under RFC 9309 a crawler obeys the
# MOST SPECIFIC group that names it, and that group ENTIRELY: it does not
# inherit a single line from the wildcard. Every group here carries "Allow: /"
# and nothing else, so today they all agree and the specificity is harmless.
# Add a "Disallow:" to the wildcard alone, though — to keep crawlers out of
# /api/, say — and every agent named below would quietly ignore it, which is
# the opposite of what the person adding the line intended. A rule that is
# meant for everyone has to be repeated in every group. tools/test-seo.mjs
# fails if the wildcard ever carries a directive the named groups do not.
#
